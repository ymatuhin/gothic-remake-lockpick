# Gothic Lockpick

This context describes the lock puzzle model for Gothic 1 Remake lock-solving.

## Language

**Пластина**:
Одна из 4-9 параллельных движущихся частей замка. Каждая **Пластина** занимает ровно одну из 7 позиций.
_Avoid_: Панель, планка; in UI use "Plate"

**Позиция**:
Одно из 7 возможных активных положений **Пластины**, нумеруемых от 1 до 7 слева направо. Позиция 4 является центральной и целевой для открытия замка.
_Avoid_: Ячейка, слот; in UI use "Position"

**Ход**:
Одно физическое движение выбранной **Пластины** влево или вправо. При физическом движении **Пластины** влево ее **Позиция** увеличивается на 1; при физическом движении вправо ее **Позиция** уменьшается на 1.
_Avoid_: Шаг, нажатие; in UI use "Move"

**Связь пластин**:
Правило, по которому **Ход** выбранной **Пластины** сдвигает дополнительные **Пластины** в ту же или противоположную сторону. Выбранная **Пластина** всегда двигается сама; **Связь пластин** описывает только дополнительные сдвиги.
_Avoid_: Зависимость, эффект; in UI use "Linked plates"

**Ошибка схемы замка**:
Некорректное описание **Связей пластин**, при котором подбор решения не запускается. Ошибкой считается конфликт направлений, повтор номера, номер самой выбранной **Пластины**, или номер вне диапазона существующих **Пластин**.
_Avoid_: Предупреждение, невалидный инпут

**Недопустимый ход**:
**Ход**, при котором хотя бы одна затронутая **Пластина** вышла бы за пределы позиций 1-7. **Недопустимый ход** не может быть выполнен.
_Avoid_: Ошибка, проигрыш

**Решение**:
Последовательность **Ходов**, которая переводит все **Пластины** в позицию 4. Каждый **Ход** в **Решении** записывается как номер **Пластины** и направление движения.
_Avoid_: Комбинация стрелок

**Оптимальное решение**:
**Решение** с минимальным количеством **Ходов**. Если существует несколько решений одинаковой длины, выбирается первое в стабильном порядке: для каждой **Пластины** сначала движение влево, затем вправо, от меньшего номера **Пластины** к большему.
_Avoid_: Лучшее решение, короткий путь

**Недостижимый замок**:
Состояние замка, для которого не существует **Решения** при заданных стартовых **Позициях** и **Связях пластин**.
_Avoid_: Нерешаемый замок, тупик

## Flagged Ambiguities

**Direction**:
Resolved: arrows in a **Решение** mean the physical direction of the moved **Пластина**, not the direction in which its numbered **Позиция** changes.

## Example Dialogue

Dev: How many plates does this lock have?
Domain expert: Six. Plate 1 starts at position 2, and Plate 4 starts at position 7.

Dev: What does move 2← mean?
Domain expert: Move Plate 2 physically left. Its active Position changes to the right.

Dev: What should the player see when the solver succeeds?
Domain expert: A compact list of plate-and-arrow moves, plus a step table with positions after each move.
